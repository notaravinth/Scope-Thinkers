# NestHub Society Management — Client

A React + Vite + Tailwind frontend for the Society Management learning project.

## UI direction

The interface was redesigned around a warm editorial/community aesthetic rather than a conventional admin dashboard:

- Deep forest + paper background
- Coral, lime, periwinkle and warm yellow accents
- Serif display typography for a more human feel
- Asymmetric dashboard composition
- Illustrated neighbourhood hero
- Animated page entrances, hover lifts and live-status pulse
- Role-aware navigation
- Responsive mobile navigation

The data/API behaviour remains the same; this redesign is primarily a frontend presentation change.

## Run

```bash
npm install
npm run dev
```
